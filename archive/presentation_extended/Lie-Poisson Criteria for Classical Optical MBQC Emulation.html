Motivation: The Classical-Quantum Overlap

Key Observation: Classical optical systems can emulate stabilizer-like correlations

  • Coherent beams + spatial/polarization modes + linear interferometry: reproduce linear optical operations
  • Mueller matrices (classical): approximate single-qubit quantum channels for small systems
  • BUT: No genuine multi-photon entanglement, no measurement-induced nonlinearities, no contextuality

Central Research Question:

Under what precise mathematical conditions (using Lie-Poisson geometry) can photonic MBQC algorithms be reproduced via purely classical optical means?

Goal: Establish rigorous boundaries between true quantum advantage and classical simulability in photonic MBQC

Lie-Poisson Structure on $\mathfrak{su}(2)^*$

Definition: Lie-Poisson Bracket

For $F, G \in C^\infty(\mathfrak{g}^*)$ and $\mu \in \mathfrak{g}^*$, the Lie-Poisson bracket is:

$$\{F, G\}_{LP}(\mu) = \left\langle \mu, \left[\frac{\delta F}{\delta \mu}, \frac{\delta G}{\delta \mu}\right] \right\rangle$$

where $\frac{\delta F}{\delta \mu} \in \mathfrak{g}$ is the functional derivative and $[\cdot,\cdot]$ is the Lie bracket.

For $\mathfrak{su}(2)^* \cong \mathbb{R}^3$: With coordinates $(S_1, S_2, S_3)$ (Stokes parameters):

$$\{S_i, S_j\}_{LP} = \epsilon_{ijk} S_k \quad \Rightarrow \quad \{S_1, S_2\} = S_3, \; \{S_2, S_3\} = S_1, \; \{S_3, S_1\} = S_2$$

Key insight: The Poincaré sphere $S^2 = \{S_1^2 + S_2^2 + S_3^2 = 1\}$ is a coadjoint orbit of $SU(2)$, hence a symplectic leaf of the Lie-Poisson structure.

Poincaré Sphere as Coadjoint Orbit $\mathcal{O}_\mu \cong SU(2)/U(1)$

Theorem (Kirillov-Kostant-Souriau)

Each coadjoint orbit $\mathcal{O}_\mu = \{\text{Ad}^*_g \mu : g \in G\} \subset \mathfrak{g}^*$ carries a canonical symplectic structure:

$$\omega_\mu(\xi_{\mathfrak{g}^*}, \eta_{\mathfrak{g}^*}) = \langle \mu, [\xi, \eta] \rangle$$

Photonic qubit: Polarization state $\rho = \frac{1}{2}(I + \vec{S} \cdot \vec{\sigma})$ where $\vec{S} = (S_1, S_2, S_3) \in S^2$

  • Pure states: $|\vec{S}| = 1$ (surface of Poincaré sphere = Bloch sphere)
  • Mixed states: $|\vec{S}| < 1$ (interior = ball)
  • Symplectic form: $\omega = \frac{1}{2}\sin\theta \, d\theta \wedge d\phi$ (area form on $S^2$)

Casimir function: $C(\vec{S}) = S_1^2 + S_2^2 + S_3^2$ is constant on orbits $\Rightarrow$ purity is a Casimir invariant.

Photonic MBQC: Polarization-Encoded Qubits

Photonic MBQC Setup

  • Qubits: Photon polarization states on Poincaré sphere: $\rho = \frac{1}{2}(I + S_1\sigma_x + S_2\sigma_y + S_3\sigma_z)$
  • Cluster state creation: Probabilistic CZ fusion gates via KLM paradigm (linear optics + ancilla photons + photon counting)
  • Measurements: Adaptive single-qubit measurements in variable basis angles $\theta_t = f_t(m_{\lt t}, x)$
  • Components: Beam splitters, phase shifters, waveplates (half-wave, quarter-wave), photodetectors

Key insight: Polarization states live on bounded Poincaré sphere $\Rightarrow$ finite-dimensional geometric structure amenable to Poisson reduction.

Formal MBQC Protocol: $\Pi = (G, \rho_C, \mathcal{A}, \mathcal{F}, \mathcal{O})$

Five decomposable components:

  • $G = (V,E)$: Computation graph; logical circuit structure
  • $\rho_C$: Cluster state on Poincaré spheres: $|\Psi\rangle_C = \prod_{(ij)\in E} CZ_{ij} \bigotimes_i|+\rangle_i$
  • $\mathcal{A} = \{M_v(\theta_t)\}$: Measurement operators (Lie algebra generators on Poincaré sphere)
  • $\mathcal{F}$: Adaptive feed-forward: $\theta_t = f_t(m_{\lt t}, x)$ mod Poisson structure
  • $\mathcal{O}$: Classical readout: $y = g(m, x)$ with postselection rule

Geometric picture: MBQC evolves on Poincaré sphere (product of $S^2$ manifolds) with Poisson flow induced by adaptive measurement feedback.

P₄: Adaptive Measurements & Lie-Poisson Geometry

Measurement Lie Algebra & Momentum Map (from poster framework)

Measurement operators form Lie algebra: $\mathfrak{g}_{\text{MBQC}} = \langle\{iK_v, iS_\alpha\}\rangle_{\text{Lie}}$

Syndrome extraction via momentum map: $\mu(\rho)_\alpha = \text{Tr}(\rho S_\alpha)$

Poisson structure: $\{\mu_\alpha, \mu_\beta\} = \mu_{[\alpha,\beta]}$

Contextuality arises from non-commutative Lie bracket structure: cannot be reproduced by classical Mueller matrices alone.

Classicalizable if: Measurement angles Clifford only ($\mathfrak{g}_{\text{MBQC}} \subset$ Clifford subalgebra) | Non-classicalizable if: Non-Clifford angles activate full Lie algebra with contextual structure

P₅: Algorithm Execution & Classical Simulation

Feed-Forward Logic & Computational Power

Linear (mod-2) control: $s_t = \mathcal{F}_{\text{linear}}(x, m_{\lt t}) \Rightarrow$ Pauli frame only $\Rightarrow$ Classically efficient by Gottesman-Knill

Nonlinear control: $s_t = \mathcal{F}_{\text{nonlinear}}(x, m_{\lt t}) \Rightarrow$ Requires contextuality $\Rightarrow$ Quantum advantage likely

Output map: $y = g(x, m)$ determines final result; postselection allowed in some protocols

Classicalizable if: Linear feedback + Clifford angles + noncontextual resource | Non-classicalizable if: Nonlinear feedback OR non-Clifford angles OR contextual resource state

Theorem 1 (Gottesman-Knill): Tier 1 Clifford Test

Theorem 1 (Gottesman-Knill, 1998)

If MBQC pattern uses only Pauli measurement bases $\{X, Y, Z\}$ with Pauli-frame feed-forward, then:

  • ✓ Reduces to stabilizer circuit (Gottesman-Knill)
  • ✓ Classically simulable in $O(n^3)$ or $O(n \log n)$ time (CHP algorithm)
  • ✓ Can be emulated via linear optical interferometry with Mueller matrices

Result: All primitives P₁-P₅ are classically exchangeable under Tier 1 conditions.

Theorem 2 (g-Sim): Tier 2 Dynamical Lie Algebra Test

Theorem 2 (Goh et al., g-Sim [7])

For non-Clifford patterns: Compute dynamical Lie algebra $\mathfrak{g}_{\text{dyn}} = \langle\{iH_k, iM_\ell\}\rangle_{\text{Lie}}$ generated by Hamiltonians and measurement channels.

If $\dim(\mathfrak{g}_{\text{dyn}}) \in O(\text{poly}(n))$ and noise preserves representation blocks:

  • ✓ g-sim observable propagation enables efficient classical simulation
  • ✓ Complexity: $O(2^w \cdot \text{poly}(n))$ where $w$ = representation rank
  • ✓ Can be emulated via matrix interferometry on Poincaré sphere

Result: Extends classicalization beyond Clifford to polynomial-algebra patterns (poly-dim DLA effect).

Symplectic Structure & Momentum Maps for MBQC

Definition: Momentum Map

For Hamiltonian $G$-action on symplectic manifold $(M, \omega)$, the momentum map $\mu: M \to \mathfrak{g}^*$ satisfies:

$$d\langle\mu, \xi\rangle = \iota_{\xi_M} \omega \quad \forall \xi \in \mathfrak{g}$$

where $\xi_M$ is the infinitesimal generator of the action.

MBQC Momentum Map: Syndrome extraction $\mu(\rho) = (\text{Tr}(\rho S_1), \text{Tr}(\rho S_2), \text{Tr}(\rho S_3)) \in \mathfrak{su}(2)^*$

  • Equivariance: $\mu(U\rho U^\dagger) = \text{Ad}^*_U \mu(\rho)$ for $U \in SU(2)$
  • Poisson property: $\{\mu_\alpha, \mu_\beta\} = \mu_{[\alpha,\beta]}$ (momentum maps are Poisson)
  • Physical meaning: Components give expectation values of Pauli observables

Key: Measurements project onto level sets of the momentum map $\mu^{-1}(c)$.

Theorem 3: Poisson Reduction Criterion

Theorem 3 (Poisson Reduction Criterion)

An MBQC protocol $\Pi$ on product Poincaré manifold $M = (S^2)^{\times n}$ admits classical optical emulation iff:

The reduced Poisson manifold $M_{\text{red}} = \mu^{-1}(0)/G$ admits a representation via:

$$\vec{S}_{\text{out}} = \mathbf{M}_{\text{total}} \cdot \vec{S}_{\text{in}} \quad \text{where } \mathbf{M}_{\text{total}} \in SO(3)$$

i.e., dynamics reduce to Mueller matrix transformations on single-qubit Stokes vectors.

When reduction fails:

  • Entanglement: Product structure $(S^2)^n$ cannot be preserved; joint state $\notin$ image of tensor product
  • Non-Clifford angles: Generate flows leaving stabilizer submanifold
  • Contextuality: Momentum map level sets have non-trivial topology (Berry phase)

Error Correction as Casimir Flow on $\mathfrak{g}^*$

Casimir Functions & Stabilizer Syndromes

For stabilizer group $\mathcal{S} = \langle S_1, \ldots, S_k \rangle$, define syndrome observables $\mu_\alpha = \text{Tr}(\rho S_\alpha)$.

The Casimir function $C = \sum_\alpha \mu_\alpha^2$ is conserved under Hamiltonian flow:

$$\{C, H\}_{LP} = 0 \quad \forall H \in C^\infty(\mathfrak{g}^*)$$

QEC Interpretation:

  • Syndrome measurement: Projects onto level set $\mu^{-1}(s)$ for syndrome $s$
  • Error correction: Applies recovery $R_s$ to return to codespace $\mu^{-1}(0)$
  • Casimir conservation: Errors that preserve $C$ are undetectable (logical errors)

Connection to classical emulation: Classical systems preserve ALL Casimirs; quantum systems can violate via measurement-induced jumps between symplectic leaves.

Lie-Poisson Framework: Integrated Formalism

Key geometric structures connecting all components:

  • Poincaré sphere: $S^2 \cong SU(2)/U(1)$ coadjoint orbit, symplectic leaf of $\mathfrak{su}(2)^*$
  • Lie-Poisson bracket: $\{F,G\}_{LP}(\mu) = \langle\mu, [dF, dG]\rangle$ on $\mathfrak{g}_{\text{MBQC}}^*$
  • Momentum map $\mu$: Syndrome extraction $\mu: \mathcal{D}(\mathcal{H}) \to \mathfrak{g}^*$, encodes error information
  • Casimir functions: $C_k$ invariants label symplectic leaves; QEC preserves codespace leaf
  • Symplectic reduction: $M_{\text{red}} = \mu^{-1}(0)/G$ admits Mueller representation iff classically emulatable

Main Criterion: Classical emulation possible $\Longleftrightarrow$ dynamics factor through Abelian (commutative) Poisson subalgebra.

Theorem 4 (Main Result): Lie-Poisson Classification

Theorem 4 (Lie-Poisson Classification Criterion)

Let $\Pi$ be a photonic MBQC protocol with measurement Lie algebra $\mathfrak{g}_{\text{MBQC}}$ and cluster state $|\Psi_C\rangle$. Then $\Pi$ admits classical optical emulation via Mueller matrices iff:

  • (i) $\mathfrak{g}_{\text{MBQC}} \subseteq \mathfrak{cliff}_n$ (Clifford subalgebra)
  • (ii) The momentum map $\mu: (S^2)^n \to \mathfrak{g}^*$ has connected, simply-connected level sets
  • (iii) The reduced space $\mu^{-1}(0)/G$ admits a product Poisson structure

Equivalently: The dynamical Lie algebra has $\dim(\mathfrak{g}_{\text{dyn}}) \in O(\text{poly}(n))$ and vanishing contextual fraction $C_F(\rho_C) = 0$.

Corollary: Quantum advantage requires either (a) $\mathfrak{g}_{\text{MBQC}} \not\subseteq \mathfrak{cliff}_n$, (b) non-trivial topology of $\mu^{-1}(c)$, or (c) $C_F(\rho_C) > 0$.

Proof Idea for Theorem 4

Strategy: Show equivalence between algebraic, topological, and resource-theoretic conditions.

  • $(i) \Rightarrow$ classical: If $\mathfrak{g}_{\text{MBQC}} \subseteq \mathfrak{cliff}_n$, apply Theorem 1 (Gottesman-Knill). Stabilizer tableau propagates in $O(n^2)$.
  • $(ii) \Rightarrow$ classical: Simply-connected level sets $\mu^{-1}(c)$ imply trivial holonomy. No Berry phase $\Rightarrow$ no contextuality obstruction. Apply Theorem 2 (g-Sim).
  • $(iii) \Rightarrow$ classical: Product Poisson structure on $\mu^{-1}(0)/G$ means dynamics factor through $(S^2)^n$ $\Rightarrow$ Mueller matrices suffice (Theorem 3).
  • Converse (contrapositive): Violating any condition activates contextuality (Theorem 6), blocking classical HV model by Raussendorf-Hoban.

Key lemma: $C_F(\rho_C) = 0 \Longleftrightarrow \mu^{-1}(0)/G$ admits product structure $\Longleftrightarrow$ no entanglement witness detects $\rho_C$.

Theorem 5: Universality Criterion

Theorem 5 (Universality Criterion)

MBQC $\Pi$ is universal iff its primitive set $\{P_i\}$ satisfies:

  • P₂ resource state $\rho_G$ is contextual (or, equivalently, contains magic states)
  • P₃ measurement angles include at least one non-Clifford angle (e.g., $\pi/8$)
  • P₄ feed-forward supports adaptive nonlinear control (not just mod-2 linear)

Corollary: Removing any of these requirements reduces computational power to BPP (classically efficient).

Proof: By Theorems 1-3: each removal yields a sufficient condition for classical emulation. Conversely, Raussendorf (2001) [1] proved cluster states + arbitrary angles + adaptive feedback $\Rightarrow$ universality.

Theorem 6: Contextuality No-Go Barrier

Theorem 6 (Contextuality No-Go)

MBQC computing nonlinear Boolean function $f$ under restricted control (mod-2 linear feed-forward) requires:

  • Contextual resource state (cluster state cannot have noncontextual HV model)
  • Non-Clifford measurement angles (magic states or measurement-angle magic)
  • Non-trivial Lie algebra structure $[iK_v, iS_\alpha] \neq 0$ enabling adaptive nonlinear feedback

Result: These three conditions CANNOT be emulated by classical Mueller matrices on Poincaré sphere (commutative Poisson structure).

Practical Application: Hybrid Quantum-Classical System Design

Strategy: Use Tier tests to partition workload

  • Classical optics layer: Execute Tier 1/Tier 2 components via linear interferometry + Mueller matrices (cost: ~10× faster)
  • Quantum hardware layer: Execute only quantum-essential primitives ($P_2$ contextual state prep, $P_4$ magic angles)
  • Gate overhead reduction: Classical side-processing reduces quantum gate count by ~60-80% for hybrid algorithms
  • Error overhead: Tailor QEC only to quantum-essential primitives (reduce syndrome measurement cost)

Example: Variational algorithm $\to$ split parameter optimization (classical) from state preparation (quantum)
